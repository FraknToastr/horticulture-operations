# Implementation Plan: Single Static Self-Contained Offline Application

Transform the Horticulture Operations Offline Overtime & Workforce Planner into a **single static self-contained application** that runs directly off the filesystem (`file://`) with zero dependencies, requiring no local live server, Node.js, or external network requests.

## User Review Required

> [!IMPORTANT]
> **Dual Architecture Strategy**:
> To maintain developer ergonomics and preserve the existing 5 automated release gates (which audit the 26 modular `.js` files and test static syntax), we will:
> 1. Preserve the modular source files (`Offline/css/style.css`, `Offline/js/**`) and preserve `Offline/index.modular.html`.
> 2. Create an automated compiler/bundler (`Offline/scripts/build_single_file.cjs`) and npm script (`npm run build`).
> 3. Make `Offline/index.html` the authoritative, 100% self-contained single-file application with all CSS, SVG icons, and JavaScript inlined directly.
> 4. Additionally emit `Offline/dist/hort_ops_offline_planner.html` for standalone distribution.
> 5. Update `Offline/scripts/test_browser_smoke.cjs` to test `file://` execution directly without starting a local HTTP server.
> 6. Fix the date-sensitive assertion in `Offline/scripts/test_scheduler.cjs` so that all 5 release gates pass 100%.

## Proposed Changes

### 1. Build Engine & Bundler Tooling
Create the canonical single-file compilation script that bundles all modular assets into a single static HTML document.

#### [NEW] [`Offline/scripts/build_single_file.cjs`](file:///home/n0rt/Antigravity-IDE/Hort_Ops_Visualisations/Offline/scripts/build_single_file.cjs)
- Reads `Offline/index.modular.html` (the modular HTML shell).
- Reads `Offline/css/style.css` and embeds it directly within a `<style>` block in `<head>`.
- Inlines all 26 JavaScript files in their strict canonical dependency order:
  1. Data: `staffRoster.js`, `initialJobs.js`, `holidays.js`, `historicalOccurrences.js`
  2. Utils: `icons.js`, `securityUtils.js`, `dateUtils.js`, `storage.js`, `eligibilityEngine.js`, `scheduler.js`, `userCsvParser.js`, `reconciliationEngine.js`, `modalUtils.js`
  3. Components: `header.js`, `forwardPlanner.js`, `calendarView.js`, `jobRegistry.js`, `staffRegistry.js`, `peakWeekends.js`, `analytics.js`, `staffAssignModal.js`, `jobEditModal.js`, `exportModal.js`, `importModal.js`, `staffExemptionModal.js`
  4. App Controller: `app.js`
- Validates that no unescaped `</script>` sequences exist within code strings.
- Writes the unified output to `Offline/index.html` and `Offline/dist/hort_ops_offline_planner.html`.
- Validates the bundled output syntax via `node --check` and reports total file size, integrity checksum, and module count.

#### [MODIFY] [`Offline/package.json`](file:///home/n0rt/Antigravity-IDE/Hort_Ops_Visualisations/Offline/package.json)
- Add `"build": "node scripts/build_single_file.cjs"`.
- Update `"test"` to run `"npm run build && node scripts/run_all_release_gates.cjs"`.
