Quick start

Import any KML, KMZ or GeoJSON file, or draw a point, line or polygon directly on the map. Toggle measurement labels using the floating toolbar.

Drawing: click to add vertices, double-click or choose Finish to complete a polyline or polygon. Press Escape to cancel; Undo removes the latest vertex. While drawing, map double-click zoom is disabled.

Conversion: export all, visible, or selected features to GeoJSON, KML or KMZ. Geometry stays in WGS84. Multiple imported documents may be combined in one export.

MetroMap: supply an API key with WMTS access. The app reads WMTS capabilities to select a Web Mercator-compatible tile matrix set supported by MapLibre. The GDA2020 service endpoint is retained.
