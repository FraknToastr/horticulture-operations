# Bundled OpenDyslexic fonts

These unmodified Regular, Bold and Italic WOFF fonts supply the existing reading-font preference in `src/shared/css/tokens.css`.

Source: https://github.com/antijingoist/opendyslexic at commit `1824da5c0e41dc3e13ffc7f3a636dcaf695d61b7`, from its `compiled/` directory.

The upstream SIL Open Font License is preserved in `OFL.txt`.
