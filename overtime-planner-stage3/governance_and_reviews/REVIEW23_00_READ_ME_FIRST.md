# Review 23 Package

This package contains the independent review of revised Gate C PR21, a bounded Gemini corrective prompt, and focused executable probes.

Copy `REVIEW23_FOCUSED_PROBES.cjs` into the application's `scripts/` directory and run:

```bash
node scripts/REVIEW23_FOCUSED_PROBES.cjs
```

The probe intentionally contains no personnel names or staff records.
